# Google Connection v2 — interface manual

1. Open settings and upload a valid Google cookies/session file.
2. Check the connection with the built-in status action.
3. Bind each shared user to a MajorDoMo object.
4. Enable forwarding to GPS Tracker if tracks and geofences are needed.
5. Use the map view for diagnostics; use scripts/API for automation.

Security: cookies are credentials. Store them only in the module settings.
